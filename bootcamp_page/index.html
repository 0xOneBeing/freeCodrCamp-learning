Bootstrap NES

Never-Ending Support for Bootstrap 3 & 4

Bootstrap 3 & 4 are already vulnerable.

Upgrades and migrations are expensive -- but security breaches and legal liability cost more. Never-Ending Support for Bootstrap 3 and 4 from HeroDevs means no upgrade or migration necessary. Fully supported, fully secured, for as long as you need.

Talk to Our Experts

Features Overview

Stay secure on Bootstrap 3 & 4 without migrating
Not ready to migrate away from older versions of Bootstrap?
With NES Bootstrap, you can stay there forever.
Your company can keep running your website(s) on Bootstrap 3 or 4 with the peace of mind that your software stack is fully supported and secured. No migration necessary.
Built by Bootstrap Core Team Members
Bootstrap NES is built and maintained by core team members of Bootstrap to ensure the same excellent quality of support you have come to expect over the years.
Expert Support
You're in the capable hands of HeroDevs' team, which includes renowned Bootstrap experts and core contributors. Expect top-tier support and the quality care that the Bootstrap community trusts.
On-Premises Peace of Mind
With Bootstrap NES, your package data never leaves your network. Our on-premises license delivery guarantees your data's security and privacy.
Proactive Security Fixes
Unsupported Bootstrap 3 and 4 means no security updates. Our proprietary scanning tool continually hunts for vulnerabilities. If a vulnerability is found, our team of Bootstrap core contributors will fix, test, and release a security patch within 14 days of vulnerability discovery.
jQuery & IE 8-11 Continued Support
Bootstrap 4 was a major rewrite. There are 53 breaking changes between Bootstrap 4 and 5. Removing jQuery and IE 8-11 support are two of those breaking changes. NES Bootstrap continues support for jQuery and IE 8-11.
Effortless Transition
Switching to Bootstrap NES takes just 5 minutes or less.

COMPATIBILITY SCANNING

Maintain Browser Compatibility
Many browser versions are no longer supported in Bootstrap 5. Internet Explorer is one of them.
We support compatibility scans for IE versions 8-11.
With our nightly build and test processes, you'll sleep well knowing that your Bootstrap application will keep running in the latest versions of all major browsers and alongside other popular open source libraries.

Maintain Compliance

Stay compliant with SLAs and regulations
Do you have an SLA with your clients to not ship unsupported libraries?
Shipping unsupported libraries puts you at risk.

Do you have FedRAMP, PCI, HIPAA, or other compliance concerns?

Our clients breeze past such concerns by having Bootstrap NES – a fully supported and secured library.

EASY TO SWITCH

Switch in less than 5 minutes
Switching from Bootstrap 3 or 4 to Bootstrap NES is done in three easy steps:
1
Sign up for Bootstrap NES
2
Configure NPM to use Bootstrap NES
3
NPM Install and run your tests

After sign up, setup and installation, you should expect to install updates regularly.
These updates will contain fixes for security issues and browser compatibility changes.

The Cost of Inaction

Discover the consequences of staying on an unsupported Bootstrap version.
Vulnerable to Cyberthreats

When Bootstrap reached the end of life, security updates stopped.

In 2017, Equifax was still using a deprecated version of Apache Struts web application framework. Hackers gained access to names, Social Security numbers, birthdates, addresses, and other sensitive information of millions of people. That vulnerability had been patched in a newer version of the Struts framework. But Equifax failed to upgrade until it was too late.

Bootstrap NES means ongoing security scans and vulnerability fixes. If a vulnerability is found, our team of Bootstrap core contributors will fix, test, and release a security patch within 14 days of vulnerability discovery.

Legal Liability

Are you bound by SLAs that mandate the use of supported software? Non-compliance can invite legal consequences, potentially leading to costly litigation. Ensure your digital operations remain within the bounds of the law.

Bootstrap NES is fully supported, which means continued compliance with your SLA.

You can read more about the cost of inaction at our blog post:
“Is There Life After End-Of-Life For Your Open-Source Software?”
Bootstrap NES can let your application live forever in version 3 or 4. Stay ahead of the curve, protect your digital assets, and maintain your compliance.
